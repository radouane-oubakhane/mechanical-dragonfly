# Stage 12 — Six articulated mechanical legs

Each leg is generated by `create_leg(leg_pair, side, scale=1.0)` in `components/step_12_legs.py`. It returns a Module with 107 meshes and 12 local rigid attachment frames. `build_stage_12(scale)` returns the six modules and cumulative scene. The right-hand geometry mirrors the left; anchor frames remain right-handed. Pairs 1 and 3 sweep forward and backward respectively, and pair 2 extends laterally.

Each leg has two hip axes, a knee, ankle, three tarsal joints, two claws, titanium reinforcement rails, carbon-composite spars, two modeled piston assemblies, a continuous nine-turn tension spring, a curved insulated harness and three encoder details. The root plate intentionally engages the chassis. Joint coordinates are in the existing body axes (+X forward, +Y left, +Z up). All translations and meshes use meters; nominal geometry is authored in mm. All six foot anchors are at z=-39 mm in the neutral pose.

## Run

```bash
python main.py --stage 12
PYTHONPATH=components python tests/test_step_12.py
python run_tests.py
```

Exports: `models/step_12_leg.glb`, `models/step_12_legs.glb`, `models/step_12_assembled.glb`. New geometry: 642 meshes; total: 3299. Nominal assembly extents: 255.714738 x 80.699411 x 59.005 mm.

## Limitations

Static neutral-pose concept. Seven pivot frames per leg are available for future animation, but no dynamic solver or moving hierarchy is implemented. Disjoint leg bounding boxes establish separation between the six legs only; no comprehensive collision check against chassis or inside joints has been performed. Piston/spring forces, electrical operation, load-bearing and real-world fabrication are not validated. Materials use PBR approximations, not textured carbon fiber. Prior regression tests are retained but not rerun in this iteration; Stage 12 checks all prior mesh coordinates and transforms.
